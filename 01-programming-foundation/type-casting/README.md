# Java Type Casting

Type casting is the process of converting a value from one data type
to another in Java.

## Topics Covered

- Widening type casting
- Narrowing type casting
- Implicit conversion
- Explicit conversion
- Data loss during narrowing conversion
- Type casting with arithmetic expressions

## Learning Goals

- Understand how Java converts values between data types
- Distinguish between widening and narrowing conversions
- Use explicit casting when required
- Understand how casting affects calculations

## Learning Approach

Understand → Analyze → Write → Run → Observe → Practice
