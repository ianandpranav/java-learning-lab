# Java Input & Output

Input and output are fundamental parts of interactive Java programs.

## Topics Covered

- Console output using `System.out.println()`
- Console input using `Scanner`
- Reading integers and decimal values
- Reading strings
- Combining input with variables and operators

## Learning Goals

- Understand how programs receive user input
- Display meaningful output
- Work with different input data types
- Build interactive console programs

## Learning Approach

Understand → Write → Run → Test → Practice
