# Java Learning Lab

This repository contains my Java learning journey, from programming
fundamentals to Object-Oriented Programming, DSA and practical projects.

I am using this repository to practice concepts by writing and running
code rather than only studying theory.

## Topics

### 01 - Programming Foundation

- Variables and data types
- Operators
- Input and output
- Type casting
- Conditions
- Loops
- Methods
- Arrays
- Strings
- Basic problem solving

### 02 - Object-Oriented Programming

- Classes and objects
- Constructors
- this keyword
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Method overloading and overriding

### 03 - Exception Handling

- try-catch
- finally
- throw and throws
- Custom exceptions

### 04 - Collections

- ArrayList
- LinkedList
- HashSet
- HashMap
- TreeSet
- TreeMap
- Queue and Deque
- Comparable and Comparator

### 05 - Advanced Java

- Generics
- Lambda expressions
- Functional interfaces
- Stream API
- File handling
- Multithreading
- Date and Time API

### 06 - DSA

- Arrays and strings
- Searching
- Sorting
- Recursion
- Linked lists
- Stack and queue
- Hashing
- Trees
- Graphs
- Dynamic programming

### 07 - Problem Solving

Regular practice of programming and DSA problems to improve
logic, problem-solving and coding skills.

### 08 - Projects

Practical Java projects to apply the concepts learned throughout
the journey.
