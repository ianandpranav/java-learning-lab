# Classes and Objects

Classes and objects are the foundation of Object-Oriented Programming in Java.

## Topics Covered

- What is a class?
- What is an object?
- Class structure
- Object creation
- Instance variables
- Instance methods
- Accessing object data and behavior
- Multiple objects from the same class

## Learning Goals

- Understand how classes model real-world entities
- Create objects from classes
- Understand object state and behavior
- Work with multiple objects

## Learning Approach

Understand → Design → Implement → Create Objects → Run → Practice
