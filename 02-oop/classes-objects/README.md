# Classes and Objects

Classes and objects are the foundation of Object-Oriented Programming
in Java.

A class defines the structure and behavior of an object, while an
object represents an actual instance created from that class.

## Topics Covered

- What is a Class?
- What is an Object?
- Class structure
- Object creation
- Fields and instance variables
- Methods and behavior
- The `new` keyword
- Accessing object members
- Multiple objects from the same class
- Object state and behavior
- Real-world object modeling
