# Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is a programming approach that
organizes software around objects that contain data and behavior.

This module covers the core concepts of OOP in Java and gradually
builds understanding from basic classes and objects to advanced
object-oriented design.

## Topics Covered

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Method Overloading
- Method Overriding
- Abstraction
- Interfaces
- Composition
- `this` keyword
- `super` keyword
- Access Modifiers
- Static Members
- Final Keyword
- Object Relationships

## Learning Approach

Each topic is learned through:

1. Understanding the concept
2. Real-world analogy
3. Writing Java code
4. Running and observing the output
5. Practicing variations
6. Solving small problems
7. Applying the concept in projects
